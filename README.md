# SR-GS

**Sampling & Rendering-aware Gaussian Splatting**

面向极端多尺度场景的采样与渲染感知层级高斯表示。

## 项目概述

针对极端多尺度场景中动态神经高斯的尺度相关采样失配与层级表示冗余问题，本项目基于 Octree-GS，研究采样感知成像与渲染感知锚点剪枝方法，在改善跨尺度成像质量的同时减少冗余锚点。

项目周期：2024.09–2026.08。

## 核心方法

- **采样感知成像**：结合三维频率约束与二维像素滤波，改善不同观察尺度下的成像质量。
- **渲染感知剪枝**：利用透射率感知的实际渲染贡献指导锚点剪枝。
- **层级高斯表示**：以 Octree-GS 为基础，研究极端多尺度场景下的表示质量与锚点规模。

## 实验结果

以下结果来自项目实验记录：在 BungeeNeRF 的 8 个极端多尺度场景上，统一训练 30,000 次迭代。

| 指标 | 结果 |
| --- | ---: |
| PSNR ↑ | 28.56 dB |
| SSIM ↑ | 0.924 |
| LPIPS ↓ | 0.089 |
| 相比 Octree-GS 的平均 PSNR 提升 | +0.425 dB |
| 相比 Octree-GS 的锚点数量减少 | 17.24% |

↑ 表示数值越高越好，↓ 表示数值越低越好。
